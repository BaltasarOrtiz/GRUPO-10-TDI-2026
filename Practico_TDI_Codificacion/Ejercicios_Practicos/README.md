# Ejercicios Prácticos — Codificación de fuente

Ejercicios de lápiz y papel del enunciado ([`../Practico_TDI_Codificacion.pdf`](../Practico_TDI_Codificacion.pdf)), Prácticos 3 y 4.

**Estado:** pendiente de resolver.

## Práctico 3 — "Compactadores"

1. Clasificación de códigos (bloque, no singular, instantáneo, unívocamente decodificable) y longitud promedio.
2. Validez de conjuntos de longitudes para código unívocamente decodificable en base ternaria; construcción de código instantáneo.
3. Demostración de que el código coma cumple Kraft.
4. Código trinario para los diez dígitos decimales con longitudes dadas; árbol de codificación.
5. Entropía y codificación estadística: Shannon, Fano y Huffman sobre una fuente de 6 símbolos; comparación de eficiencia y redundancia.
6. Método de diccionario LZ y LZW sobre la cadena `ERRECONERRECIGARROERRECONERREBARRIL`.
7. Codificación aritmética sobre la secuencia `ABACA`.
8. Fuentes de Markov: matriz de transición, distribución estacionaria, ergodicidad, dependencia lineal de filas.
9. Ejercicio 6 del Práctico 3 como fuente de Markov de orden 1 (Huffman, Fano, Shannon, codificación predictiva, BWT + RLE).

## Práctico 4

1. Comprobación de la desigualdad de Kraft (Hr ≤ 1) para varios conjuntos de probabilidades.
2. Longitud mínima de código para fuentes equiprobables.
3. Codificación trinaria por Huffman sobre una fuente de 7 símbolos.
4. Huffman, Shannon y Fano sobre una fuente de 3 símbolos; segunda y tercera extensión.
5. Segunda extensión por Fano del texto `PABLITOPABLITOPABLOCLAVO`; comparación con Markov de orden 1.
6. Pipeline BWT → RLE → Huffman sobre la cadena `TOMATOMATOMA$`.
